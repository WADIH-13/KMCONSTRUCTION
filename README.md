## 📦 Installation et déploiement

### Déploiement local

1. Cloner le repository
2. Ouvrir `index.html` dans un navigateur
3. Ou utiliser un serveur local:
   ```bash
   python3 -m http.server 8000
   ```
   Puis accéder à `http://localhost:8000`

### Déploiement sur GitHub Pages

1. Pousser le code sur GitHub
2. Aller dans Settings > Pages
3. Sélectionner la branche `main` et le dossier `/` (root)
4. Le site sera accessible à `https://[username].github.io/[repo-name]`

### Sources recommandées pour les photos:

- **Unsplash:** https://unsplash.com/
  - Recherches: "construction site", "masonry", "brick wall construction"
- **Pexels:** https://www.pexels.com/
  - Recherches: "building construction", "construction worker"

### Optimisation des images:

- Compresser avec TinyPNG.com ou ImageOptim
- Taille cible: < 500KB par photo
- Format: JPG pour photos, PNG pour logo
