## How to Add Real Images:

1. Visit Unsplash.com or Pexels.com
2. Search for the keywords listed above
3. Download high-resolution images (free to use)
4. Optimize images for web (compress to reduce file size)
5. Rename images according to the filenames above
6. Place them in this `/images` directory

## Image Optimization Tips:
- Use tools like TinyPNG.com or ImageOptim to compress images
- Target file sizes: < 500KB for photos, < 100KB for logo
- Convert to WebP format for better performance (with JPG fallback)
- Ensure proper aspect ratios for responsive display
